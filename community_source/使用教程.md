# 使用教程

## 一、系统要求

- Windows 10 或 Windows 11，64 位
- Steam 正版《逸剑风云决》
- 解压后约 11GB 可用空间（下载和解压期间建议预留至少 20GB）
- 能正常播放 WAV 的声音设备

不需要安装 Python、Conda、PyTorch、CUDA、Qwen 模型或 .NET SDK，也不要求 NVIDIA 显卡。

## 二、下载与解压

1. 下载完整发布压缩包。
2. 使用 Windows、7-Zip、Bandizip 等工具完整解压。
3. 建议解压到路径较短的位置，例如 `D:\Games\WanderingSwordVoiceMod`。
4. 不要直接在压缩软件窗口里双击脚本，否则播放器找不到音频。

解压后应能看到：

```text
1_一键安装Mod.cmd
2_启动配音并启动游戏.cmd
3_仅启动配音.cmd
4_检查安装.cmd
5_卸载Mod.cmd
6_设置播放速度.cmd
data/
payload/
runtime/
```

## 三、首次安装

双击 `1_一键安装Mod.cmd`。

安装器会依次尝试：

1. 读取 Steam 注册表与 `libraryfolders.vdf`；
2. 检查常见 Steam 库目录；
3. 检查发布包的父目录；
4. 如果仍然找不到，请手动粘贴包含 `JH.exe` 的游戏根目录。

正确的游戏根目录类似：

```text
D:\SteamLibrary\steamapps\common\Wandering Sword
```

安装器只会把 UE4SS 运行时和 `WanderingSwordVoiceProbe` 事件桥放入游戏的 `Wandering_Sword\Binaries\Win64`。它会自动把 UE4SS 引擎版本配置为 UE 4.26。如果已经安装 UE4SS，现有 UE4SS 文件和其他 Mod 会被保留；修改既有设置前会创建一次 `UE4SS-settings.ini.wsvoice-backup` 备份。

如果 Steam 安装在 `C:\Program Files (x86)` 且提示没有权限，请右键 `1_一键安装Mod.cmd`，选择“以管理员身份运行”。

## 四、检查安装

双击 `4_检查安装.cmd`。

正常情况下会依次显示：

```text
[OK] Game executable
[OK] UE4SS proxy
[OK] UE4SS runtime
[OK] Voice bridge
[OK] Compact lookup
[OK] Audio directory
[OK] WanderingSwordVoiceProbe is enabled in mods.txt
[OK] UE4SS engine version override: 4.26
Player self-test passed.
Everything is ready.
```

第一次安装且还没有启动过游戏时，运行态桥接检查会显示一条 `[INFO]`，这是正常现象。启动一次游戏后再次检查，应显示 `Runtime bridge` 已成功启动。

## 五、开始游玩

推荐双击 `2_启动配音并启动游戏.cmd`。它会先加载离线索引，再通过 Steam 启动游戏。

播放器显示：

```text
[READY] 87087 exact, 84159 text fallback, 19 prefix lines.
No AI model, Python, CUDA, or network connection is used.
```

进入游戏并出现正式人物对白后，会看到：

```text
[PLAY] 人物名：当前台词
```

也可以先自行启动游戏，再双击 `3_仅启动配音.cmd`。播放器启动后默认只监听新出现的对白，不会重播历史事件。

## 六、播放规则与速度

- 推进到下一句时，上一句配音会立即停止，避免对白串音。
- 相同人物、相同台词会复用同一个音频。
- Windows 音量合成器可以单独调节 PowerShell 窗口的输出音量。
- 按播放器窗口中的 `Ctrl+C` 可以停止配音，不影响游戏。
- 关闭游戏后可以直接关闭播放器窗口。

如果觉得语音偏慢，关闭播放器后双击 `6_设置播放速度.cmd`。可输入 `1.00～1.50` 之间的数值：

- `1.00`：原始速度；
- `1.10`：轻微加快，推荐先尝试；
- `1.20`：明显加快；
- `1.30`：快速播放。

设置会保存到 `config\playback_speed.txt`，重新启动播放器后生效。播放器会使用内置时间拉伸尽量保持人物原有音高，不需要安装 FFmpeg 或其他软件。变速只生成一个反复覆盖的临时 WAV，不会额外占用一整套音频空间。如果单条音频变速失败，播放器会显示 `[SPEED FALLBACK]` 并自动按原速播放，不会造成该句静音。

## 七、未收录台词

若窗口显示：

```text
[MISS] 人物名：台词
```

说明游戏更新、文本动态变化或当前社区版未收录该句。事件会保存到：

```text
logs/unmatched_dialogue.jsonl
```

反馈问题时请提供该文件、游戏版本以及问题截图，不要提供个人隐私或存档。

## 八、升级

1. 关闭游戏和播放器。
2. 完整解压新版到新的目录，避免新旧文件混杂。
3. 再次运行新版 `1_一键安装Mod.cmd`。
4. 运行 `4_检查安装.cmd`。

安装器会更新事件桥并保留其他 UE4SS Mod。

从任何旧版升级时，都应完整解压到新目录并重新运行一次 `1_一键安装Mod.cmd`。v1.1.0 起会更新剧情过场事件桥，同时自动补齐 UE 4.26 配置；v2.0.0 新增可保存的自定义播放速度，不需要手工编辑脚本或 INI。

## 九、卸载

1. 关闭游戏和播放器。
2. 双击 `5_卸载Mod.cmd`。
3. 输入 `YES` 确认。

卸载器只删除 `WanderingSwordVoiceProbe`，不会删除 UE4SS，避免破坏玩家的其他 UE4SS Mod。之后可手动删除整个发布包目录以释放约 11GB 空间。
