# 逸剑风云诀全离线 AI 配音 Mod

这是面向普通玩家的无模型运行时模板。它负责安装 UE4SS 对话桥、读取离线索引、
播放预生成语音和调整播放速度。

> 本目录本身不是完整 Mod。开源仓库虽然包含对白目录、角色注册表、角色画像和
> 声线规划，但不包含 AI 配音、运行时索引、UE4SS 二进制文件或模型权重。

完整社区包构建完成后，玩家通常按以下顺序使用：

1. 完整解压发布包；
2. 双击 `1_一键安装Mod.cmd`；
3. 双击 `4_检查安装.cmd`；
4. 以后通过 `2_启动配音并启动游戏.cmd` 游玩；
5. 如需调整语速，运行 `6_设置播放速度.cmd`。

实现原理与复现步骤见仓库根目录的 `README.md` 和 `docs/`。
