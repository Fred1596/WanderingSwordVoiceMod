# 安全、版权与发布边界

本文不是法律意见，只说明本仓库采取的技术隔离措施。

## 仓库包含什么

- 原创 Python、PowerShell、Lua、Shell 和批处理源码；
- 虚构的示例配置与数据格式；
- 项目最终使用的完整对白目录快照、角色注册表、角色画像和声线规划；
- 架构、复现和故障排查文档。

## 仓库不包含什么

- 游戏 `.pak`、`.locres`、`.uasset` 或 DataTable 导出；
- 游戏 `.pak` 中的其他原始内容、人物头像或其他美术资产；
- 生成的 WAV 或声线锚点；
- Qwen3-TTS、PyTorch、UE4SS 或工具二进制；
- API Key、登录凭据、服务器地址、日志或本机绝对路径；
- 可直接安装的完整社区 Mod 包。

## 使用者责任

使用者应自行确认：

1. 对游戏安装和所处理内容拥有合法访问权；
2. 资源提取和 Mod 行为符合所在地法律、游戏协议和平台规则；
3. 模型、API 和第三方工具的许可证及服务条款允许其用途；
4. 生成音频的发布、商业化和再分发获得必要权利；
5. 不再向仓库添加本项目明确公开的数据快照以外的游戏内容或他人资产。

公开数据快照包含游戏文本或其衍生分析，不适用代码的 MIT License。维护者应准备
接收权利人或平台的下架请求，并在需要时移除相关数据。

## API Key

代码只从环境变量读取密钥。推荐使用当前终端的临时环境变量，或操作系统的凭据
管理方案。不要把密钥写入 `.py`、`.json`、`.cmd`、日志或截图。

一旦密钥进入 Git 历史：

1. 立即到服务商控制台吊销；
2. 创建新密钥；
3. 使用历史清理工具删除泄露内容；
4. 强制推送前通知所有协作者重新同步。

## 第三方二进制

不要把下载到本地的 UE4SS、repak、UAssetGUI、umodel、模型权重或未知 DLL 提交到
仓库。让使用者从原项目下载，既能保留来源和许可证，也能减少供应链风险。

## 负责任的社区发布

如需发布完整音频 Mod，应独立于本源码仓库，并清晰提供：

- 非官方声明；
- 生成模型和第三方组件来源；
- 文件哈希；
- 免费/非商业属性（如适用）；
- 下架和反馈渠道；
- 不要求玩家关闭所有安全防护的安装说明。
